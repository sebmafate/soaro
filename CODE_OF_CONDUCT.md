# Code of conduct

This project is open to everyone, whatever your experience, background or language.

## What I expect

- Be kind and respectful. Disagree with ideas, not with people.
- Be patient. Many people here are volunteers, and English is not everyone's first language.
- Give useful feedback, and accept it the same way.
- Assume good intentions, and ask when something is not clear.

## What is not accepted

- Insults, harassment, or personal attacks
- Discrimination of any kind
- Publishing someone's private information
- Spam, and anything that is not related to the project

## Enforcement

I may edit or remove comments, issues and pull requests that break these rules, and I may block people who do it again. To report a problem, use the contact address on my GitHub profile. Reports are handled privately.

This code applies in the repository and in any space where someone represents the project.
